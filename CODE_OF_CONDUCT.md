# Code of conduct

tectra is a place to build an Angular UI kit together. Everyone who opens an issue, a discussion or a pull request is welcome, whatever their experience, background or the language they write best in.

## Expected

- Be kind and assume good intent. Explain the reason behind a request or a review comment.
- Keep feedback about the code and the product, not about the person.
- Accept that a proposal may be declined, and say why when you decline one.
- Help newcomers: point them to the docs, the contributing guide or an example.

## Not accepted

- Harassment, insults, discriminatory language or imagery, personal or political attacks.
- Publishing someone's private information without their permission.
- Spam, trolling, or repeatedly pushing a topic after it was declined.

## Enforcement

The maintainer may edit or remove comments, close issues or pull requests and block people who do not follow these rules. Report a problem privately to the maintainer through the contact on the GitHub profile; reports are kept confidential.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
