# generated (not in git)

Written by `tools/registry-builder/build-registry.mjs` before every docs build / serve. `registry.ts` is the small index the app loads at start: name, title and category of every component plus a lazy loader. `components/<name>.ts` holds one page — description, API (types and defaults from the source, descriptions from the package README), CSS variables, keyboard table and the examples with highlighted code and lazy imports — and is loaded by the route resolver. `version.ts` holds `TECTRA_VERSION`, read from `packages/tectra-ng/package.json`, so the header badge follows every release.
