# generated (not in git)

Written by `tools/registry-builder/build-registry.mjs` before every docs build / serve. `registry.ts` is the small index the app loads at start: name, title and category of every component plus a lazy loader. `components/<name>.ts` holds one page — description, API (types and defaults from the source, descriptions from the package README), CSS variables, keyboard table and the examples with highlighted code and lazy imports — and is loaded by the route resolver. `version.ts` holds `TECTRA_VERSION`, read from `packages/tectra-ng/package.json`, so the header badge follows every release. `stackblitz.ts` holds `STACKBLITZ_SETUP` for the "Open in StackBlitz" button: the kit version, the Angular, RxJS and TypeScript versions of the workspace `package.json`, and the CSS of `src/_example-utilities.scss` (the `.flex`, `.stack`, `.hint` and `.reveal` classes the examples use).
