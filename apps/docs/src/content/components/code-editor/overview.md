# Code editor

An editor for HTML, CSS, JavaScript, TypeScript, JSON and Markdown: syntax colours from the design tokens, line numbers, undo, smart indents, auto-closed brackets and tags, comments with Ctrl/⌘+/, search and replace, and form support. The page is rendered on the server as highlighted code and turns into the editor after hydration.

Its own package — install it separately, `tectra-ng` does not include it: `npm install @tectra-ng/code-editor`.
