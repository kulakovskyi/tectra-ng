`home` is the first item; give an icon-only item an `ariaLabel`. `routerLink` navigates with the Angular router (`queryParams` and `fragment` are passed along) — these links open other pages of this site; `url` + `target` make a plain link. Links carry a light underline that darkens on hover; an item without a link or command (`Components`) is plain text, so it does not pass for a link. The last item of `model` is the current page.
