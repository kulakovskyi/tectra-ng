# Cookie Notice

A small card in the corner about essential cookies, with a "Learn more" link and a "Got it" button; the choice is kept in a cookie.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
