# Gauge

One value on a scale — a progress arc in a tone, or a needle over coloured bands such as good, warning and critical. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
