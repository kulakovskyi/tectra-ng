# Sunburst Chart

A hierarchy as nested rings — each ring is a level, each segment its share of the parent. Click a segment to zoom in, the centre to go back. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
