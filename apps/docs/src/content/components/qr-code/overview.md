# QR Code

A string drawn as a QR code with tectra's own encoder — no dependency. Dots and corner eyes in several shapes, colours and gradients, a logo in the middle, download as PNG or SVG.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks @tectra-ng/qr`.

The engine is its own package, `@tectra-ng/qr`: plain TypeScript with no dependencies, so the same codes can be made in any framework, in Node or on the server — `npm install @tectra-ng/qr`.
