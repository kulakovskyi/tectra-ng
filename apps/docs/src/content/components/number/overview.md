# Number

Numbers in the tectra locale with any `Intl.NumberFormat` option — fraction digits, percent, units, compact notation — and `-` instead of `NaN` for an empty or broken value.

Part of `@tectra-ng/utils` (`npm install @tectra-ng/utils`, also included in `tectra-ng`).
