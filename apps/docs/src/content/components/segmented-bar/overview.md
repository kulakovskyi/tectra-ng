# Segmented Bar

Parts of one whole in one bar with a legend: each segment is as wide as its share and coloured by a tone. A thin bar for cards and table rows, a tall one with the percent inside each segment.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
