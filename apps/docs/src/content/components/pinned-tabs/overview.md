# Pinned Tabs

Quick-switch tabs for a filter with many values: the user pins the values they use often, and they appear as tabs next to "All". The choice is saved in the browser.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
