# Treemap

Shares of a total as rectangles sized by value, with names and values inside the tiles that fit and nested groups. Drawn as SVG, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
