# Confetti

A one-time burst of confetti from the middle of its box — for a finished onboarding, a confirmed e-mail or a changed password.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
