# Plural

Plural forms by the language rules: one file, 3 файли, 5 файлів. The pipes follow the tectra locale, also when it changes at runtime.

Part of `@tectra-ng/utils` (`npm install @tectra-ng/utils`, also included in `tectra-ng`).
