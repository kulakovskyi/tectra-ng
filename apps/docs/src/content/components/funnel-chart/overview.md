# Funnel Chart

How many pass each step of a process — visits, sign-ups, trials, purchases — with the conversion from the step before. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
