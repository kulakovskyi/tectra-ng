# Scatter Chart

Points on two value axes to see how two measures relate — and bubbles when a third value sets the size. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
