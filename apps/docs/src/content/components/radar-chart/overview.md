# Radar Chart

Values of several series on axes spread around a centre — compare profiles, skills or ratings at a glance. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
