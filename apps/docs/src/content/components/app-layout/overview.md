# App Layout

The shell of a signed-in app: a sidebar menu that folds into a rail of icons, a top bar, the page and a footer. Below 1024px the menu hides behind a button and slides in over the page.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`. The examples sit in a 560px screen (`contain: layout` keeps the mobile menu and the backdrop inside it); in an app the layout fills the window.
