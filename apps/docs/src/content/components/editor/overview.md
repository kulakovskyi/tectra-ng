# Editor

A rich text editor with a toolbar, a menu over selected text, a `/` block menu, links, colours, lists, checklists, tables, callouts, images, video, `@` mentions, `:` emoji, Markdown shortcuts and AI actions. It writes clean HTML or Quill markup and reads both.

Its own package — install it separately, `tectra-ng` does not include it: `npm install @tectra-ng/editor`.
