# Filters Panel

A card with the filter fields above a table or a list. Users pick which filters are shown and drag them into their own order; the choice is saved per panel. Below 1024px the fields fold into a "Filters" button with the number of active filters.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
