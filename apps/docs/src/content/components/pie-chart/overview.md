# Pie Chart

A donut or pie for parts of a whole: the total in the centre, the hovered segment's value, percent labels on the segments and a legend that can list values and shares. Drawn as SVG, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
