# Title

Browser tab titles from the routes — "Orders · Console" — with a prefix for counters and translated title keys. Set it up once with `provideTxTitle({ appName })` next to `provideRouter`.

Part of `@tectra-ng/utils` (`npm install @tectra-ng/utils`, also included in `tectra-ng`).
