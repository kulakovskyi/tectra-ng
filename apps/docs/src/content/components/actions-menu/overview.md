# Actions Menu

The "more" button of a header, a panel or a card: an outlined `⋯` button with a short list of actions in a popover; destructive actions are red.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
