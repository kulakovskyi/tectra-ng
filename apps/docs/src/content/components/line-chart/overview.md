# Line Chart

A smooth area or line chart for trends over time. It is drawn as SVG by the component itself — no chart library — renders on the server, and takes every colour from the design tokens, so themes and dark mode just work.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
