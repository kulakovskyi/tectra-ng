# Column Chart

Columns or horizontal bars for comparing values across categories — grouped side by side (the default), stacked or 100% stacked. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
