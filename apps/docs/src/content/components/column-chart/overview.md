# Column Chart

Columns or horizontal bars for comparing values across categories — stacked, 100% stacked or grouped side by side. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
