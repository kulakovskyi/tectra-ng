# Sankey Diagram

How an amount flows between stages — traffic sources into pages and outcomes, a budget into departments. Links are as wide as their value. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
