# Rank Chart

Positions over time with rank 1 on top: one line per series at real check times, gaps for checks without a rank, notes in the tooltip. Drawn as SVG, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
