# Combo Chart

Columns and lines in one plot, each series on the main or a second value axis — amounts in columns with a rate or a trend line over them. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
