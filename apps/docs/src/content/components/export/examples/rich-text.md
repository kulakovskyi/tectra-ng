`TxExportService.exportHtmlPdf(source, options)` turns rich HTML — a string, or an element whose content is read — into a paged PDF with real, selectable text: headings, paragraphs, bold, italic, links and code, nested lists, quotes, code blocks and tables whose header row repeats on every page. `writeHtmlPdf` does the same without the service and returns the blob; a string is read without a DOM, so it also runs on the server.
