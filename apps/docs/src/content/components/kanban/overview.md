# Kanban

A board of columns with cards that move inside and between columns, and columns that move by their handle — with the pointer or with Alt and the arrow keys. The board reports each move; the page keeps the state.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
