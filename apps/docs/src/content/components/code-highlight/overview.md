# Code highlight

Highlighted code without an editor: the same tokenizers and colours as the code editor, rendered on the server, no engine loaded. For snippets, logs and read-only files. `highlightCode(code, language)` gives the tokens for your own markup.

Part of `@tectra-ng/code-editor` — install it separately: `npm install @tectra-ng/code-editor`.
