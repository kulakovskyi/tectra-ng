# Radial Bar

Progress of one or several items as concentric rings over a track — goals, quotas, completion. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
