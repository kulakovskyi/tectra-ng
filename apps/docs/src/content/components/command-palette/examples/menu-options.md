`menuPaletteItems` takes options: `translate` turns the menu labels — translation keys here — into text, section titles included, and `icon` maps the menu icons to the icons of the palette (an object or a function of the item); `defaultIcon` is used for items without one. Switch the language and search again. This palette opens with ⌘E / Ctrl E. `hintTexts` replaces the texts of the key hints in the footer for a language tectra has no translation of.
