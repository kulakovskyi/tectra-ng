# Command Palette

A search button for the top bar and a ⌘K / Ctrl K window with grouped results that the keyboard moves through. Enter opens a page through the router or runs an action.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
