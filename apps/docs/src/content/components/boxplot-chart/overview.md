# Box Plot

How values spread in each category — quartiles, median, whiskers and outliers, several series side by side. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
