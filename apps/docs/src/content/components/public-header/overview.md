# Public Header

The sticky header of public pages: the brand, the links, the language and theme preferences and the actions; below 768px they fold behind a burger.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
