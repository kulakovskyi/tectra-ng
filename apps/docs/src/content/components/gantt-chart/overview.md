# Gantt Chart

Tasks as bars on a calendar — groups that fold, progress, milestones and a line for today, scrolled and zoomed from days to quarters. The timeline layout puts every task of a group on one lane.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
