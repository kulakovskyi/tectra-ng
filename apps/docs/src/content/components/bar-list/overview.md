# Bar List

A top-N ranking: a label over a bar scaled to the biggest value, the formatted value and its share of the total. Sorted from the biggest value, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
