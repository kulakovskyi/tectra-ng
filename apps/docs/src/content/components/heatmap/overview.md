# Heatmap

A grid of rows × columns grouped in bands, each cell coloured by a tone or a value. Sticky headers, a value column, tooltips per cell, a legend and a calendar helper for a year of days.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
