`minWidth` sets the narrowest column before the grid wraps — here wider tiles that wrap sooner. Without it columns stay at least `210px` (the `floorWidth` token) unless the grid is `compact`; an explicit `minWidth` wins over that floor. `floorWidth` keeps a floor under `minWidth` — the second grid asks for `8rem` columns but never goes below `13rem`, so its long labels stay readable.
