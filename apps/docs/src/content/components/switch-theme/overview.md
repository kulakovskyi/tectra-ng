# Switch Theme

A round button that switches the light and the dark theme: the sun and the moon swap with a turn and the new theme grows as a circle from the click.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
