# Candlestick Chart

Prices over time as candles or OHLC bars — open, high, low and close of each period with the volume under them. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
