`tx-console-panel` puts a sticky list or tree on the left of a page — mark it `txConsolePanelAside`. The panel gives the list its spacing, so the menu here drops its own outer spacing with `dt`; its items run commands and mark the current project with `active`. The panel takes the whole content area and moves the layout footer under its page; below 1024px it folds into a bar above the page.
