In an app the rail sections are router links. `activeOptions` decides when a section is current — `TX_CONSOLE_RAIL_SECTION_MATCH` keeps it active on its child pages, `TX_CONSOLE_RAIL_EXACT_MATCH` suits the home section. The crumbs come from the `crumb` value in the `data` of the active routes; this example keeps its sections in the query of the docs page and passes the crumbs itself.
