# Console Layout

The frame of an "app inside an app" console: a sticky header with the brand and the crumbs, an icon rail of sections, the page and a footer. `tx-console-panel` adds a sticky list or tree on the left of a page.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`. The examples sit in a 560px screen; `dt` tells the layout that height, in an app it fills the window.
