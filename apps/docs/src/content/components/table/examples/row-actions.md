Row actions go into `<ng-template txTableActions>` as `tx-table-actions` with buttons marked `*txTableAction="{ label }"`; an action may sit inside `@if` — here the reminder is only for unpaid invoices. `actionsInlineCount` actions stay in the row, the rest open from `…`, which closes once an action is clicked; a right-click on a row shows all of them as a menu. With `actionsSettings` the gear lets the user reorder and pin actions. `[txTableActionsOf]` takes the rows only for typing, so `let-invoice` has their type in strict templates.
