Below `breakpoint` (64rem) every row becomes a card: header labels on the left, the first column (or `cardTitle`) as the title, the checkbox in the corner, an expand button when the table has `txTableExpansion`, and the actions at the bottom. Group headers and footers of `groupRowsBy` stay between the cards. This example uses `breakpoint="200rem"` so the cards show on any screen; `<ng-template txTableCard>` draws an own card instead.
