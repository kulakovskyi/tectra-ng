`resizableColumns` adds drag handles between headers. `reorderableColumns` lets any header be dragged along the header row by the grip that shows on hover (Alt + arrows on a header from the keyboard) and turns the column list of the gear into a sortable list — drag a row or press Alt + Arrow Up / Down on its checkbox. A column with `reorderable: false` stays in place, `hideable: false` keeps it visible (Invoice here). With `stateKey` widths, order, hidden columns and the sort are saved in local storage — reload the page to see them back.
