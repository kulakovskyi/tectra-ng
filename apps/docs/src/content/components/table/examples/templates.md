`<ng-template txTableCell="field">` replaces the content of a column; the template gets the row, `value`, `index` and `column`. Cells take any content — pills, amounts, buttons with popovers (the info button next to the client). `[txTableCellOf]` takes the rows only for typing, so `let-invoice` has the row type in strict templates. `txTableHeaderCell` replaces a header.
