Items with `routerLink` are router links. The item of the current route is highlighted (a subset match by default, `routerLinkActiveOptions` to change it) and its parents open when you navigate. Here each link writes a query parameter, so the page stays. An item with nested items does not navigate, so on the pages of its own link it only opens. When a link has an own item for one of its sub-pages — `/projects` next to `/projects/owners` — give the parent `routerLinkActiveExclude: ['/projects/owners']` so only one of them is highlighted.
