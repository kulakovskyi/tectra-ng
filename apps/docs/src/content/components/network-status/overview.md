# Network Status

A pill at the bottom of the window: "No internet connection" while offline, "Connection restored" for three seconds once the browser is back online.

A block from `@tectra-ng/blocks` — it comes with `tectra-ng`, or alone: `npm install @tectra-ng/blocks`.
