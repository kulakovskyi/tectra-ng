# Range Area Chart

A band from a low to a high value with an optional line inside — temperature from min to max with the average, a forecast with its confidence range. Drawn as SVG by the component, rendered on the server and themed by the design tokens.

Part of `@tectra-ng/charts` (`npm install @tectra-ng/charts`, also included in `tectra-ng`).
