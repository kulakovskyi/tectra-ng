Theming

A preset is data. provideTectra() turns it into CSS variables — change it and everything repaints.

A preset has three parts: a primary palette for actions and selection, a surface palette for backgrounds, borders and text, and a theme — the shape of every component (radius, spacing, focus ring, density). The same picker sits behind the palette button in the header.
