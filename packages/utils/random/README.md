# Random

Pick one or several different items from a list — tips, sample data, avatars for a placeholder — or shuffle it. Pass your own random function for repeatable results in tests.

## Functions
| Name | Description |
|---|---|
| pickRandom(items, random?) | One item, or `null` for an empty list |
| pickRandomN(items, count, random?) | Up to `count` different items |
| shuffle(items, random?) | A shuffled copy; the input stays as it is |
