# Input

Styles a native `input` or `textarea`. Works with `[formControl]`, `ngModel` and signal forms as is — it is the native element.

## Inputs
| Name | Description |
|---|---|
| invalid | Red border and `aria-invalid`, e.g. `[invalid]="control.invalid && control.touched"` |
| size | Height and font size |

## Keyboard
| Key | Action |
|---|---|
| Tab | Moves focus to the field (native behaviour) |
