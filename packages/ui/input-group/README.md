# InputGroup

Joins a field with addons — text, icons, buttons, selects — into one block with shared borders.

```html
<tx-input-group>
  <tx-input-group-addon>https://</tx-input-group-addon>
  <input txInput placeholder="site" />
  <tx-input-group-addon>.com</tx-input-group-addon>
</tx-input-group>
```

## Inputs
| Name | Description |
|---|---|
| fluid | Takes the full width of its container; inherits `<tx-fluid>` |

## Keyboard
| Key | Action |
|---|---|
| Tab | Moves through the field and the buttons inside the group |
