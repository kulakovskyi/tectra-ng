# Button

Triggers an action. An attribute on a native `button` or `a`, so all native behaviour (type, disabled, href, focus) stays.

## Inputs
| Name | Description |
|---|---|
| severity | Meaning of the action: `primary` main, `secondary` neutral, `success`, `info`, `warn`, `danger` destructive, `help` |
| size | Height and padding |
| outlined | Transparent background with a coloured border |

## Keyboard
| Key | Action |
|---|---|
| Enter / Space | Triggers the button (native behaviour) |
| Tab | Moves focus to the button |
