# @tectra-ng/icons

334 outline icons drawn for tectra on a 24 × 24 grid: round caps and joins, one stroke width, filled variants where the name says `-fill`. Names are plain words (`check`, `times`, `pencil`, `chevron-down`, `sort-amount-up-alt`…); a `pi-` prefix is accepted and dropped. Brand logos are not part of the set.

```html
<tx-icon [name]="'trash'" />
```

## Register the icons

Components of the kit bring the icons they draw themselves. The names your own templates use are registered once in `app.config.ts` — the whole set, or only what the app needs, so the rest stays out of the bundle (every icon is its own constant, `txIcon` + the name in PascalCase):

```ts
provideTxIcons(TX_ICONS);

provideTxIcons({ plus: txIconPlus, trash: txIconTrash });
```

A name nobody registered draws nothing; in development the console says which name is missing. Icons you register replace the built-in ones of the components with the same name.

`TX_ICONS` and the `txIcon…` constants are generated by `tools/icons/build-icons.mjs` from `tools/icons/defs/*.mjs` — edit the definitions there, never `icons.ts`. The icons each entry point of the kit draws are listed in its generated `<name>.icons.ts` (`npm run icons:defaults`; CI fails when a list is out of date) and given to its components with `provideTxIconDefaults`.

## Inputs
| Name | Description |
|---|---|
| name | Icon name — one of the 334 tectra icons or any icon registered with `provideTxIcons` |

## More icons
`provideTxIcons(set)` in `app.config` adds icons to the registry, so `<tx-icon>` and every `[icon]` input (button, toggle-button) can use them by name. A set is `{ name: paths[] }` on the 24 × 24 grid; a path is a `d` string (stroked) or `{ d, fill: true, stroke: false, transform }`. Brand logos ship this way in `@tectra-ng/brand-icons`; your own logo goes the same way:

```ts
provideTxIcons({ 'my-logo': [{ d: 'M…', fill: true, stroke: false }] })
```

`TxIconRegistry` (`register`, `get`, `has`) is the registry of the app; `injectTxIcons()` looks a name up in it and in the defaults of the surrounding component.

## Design tokens
| Token | Description |
|---|---|
| `--tx-icon-size` | Width and height, `1em` by default — the icon follows the font size |
| `--tx-icon-stroke-width` | Line thickness on the 24 px grid, `1.75` by default |
