# Support

## Where to ask

| You want to… | Go to |
|---|---|
| Learn how a component works | [tectra-ng.com](https://tectra-ng.com) — every component with live examples and its API |
| Ask how to do something | [Discussions → Q&A](https://github.com/kulakovskyi/tectra-ng/discussions/categories/q-a) |
| Suggest an idea or a new component | [Discussions → Ideas](https://github.com/kulakovskyi/tectra-ng/discussions/categories/ideas) or a [feature request](https://github.com/kulakovskyi/tectra-ng/issues/new?template=feature.yml) |
| Report a bug | [A bug report](https://github.com/kulakovskyi/tectra-ng/issues/new?template=bug.yml) with the tectra and Angular versions and a minimal reproduction |
| Report a vulnerability | Privately, as described in [SECURITY.md](SECURITY.md) — never in a public issue |

## What is supported

The latest minor version of tectra on npm, with the Angular major version it lists as a peer dependency. Fixes land in the next release; older versions do not get backports.

## Before you ask

- Search [issues](https://github.com/kulakovskyi/tectra-ng/issues?q=) and [discussions](https://github.com/kulakovskyi/tectra-ng/discussions) — it may already be answered.
- Check the component's API tab on the docs site and the [CHANGELOG](CHANGELOG.md).
